# Амина — Telegram Recruitment Bot

Telegram-бот для учёта анкет, собеседований, испытательного срока, голосований и репутации (REP). Бот хранит записи и напоминает о событиях; решения принимают люди.

## Стек
- Python 3.11
- aiogram 3
- SQLite через aiosqlite

## Запуск локально
1. Установите Python 3.11.
2. Создайте окружение: `python -m venv .venv`
3. Активируйте окружение и установите зависимости: `pip install -r requirements.txt`
4. Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN`.
5. Запустите `python bot.py`.

**Не добавляйте `.env`, токены или другие секреты в Git.**

## Разделы меню
- Анкеты
- Собеседования
- Испытательный срок (14 дней)
- Голосования (24 часа)
- Репутация
- Настройки

Начинаем с минимального запуска `/start`; функциональность разделов добавляется постепенно.
