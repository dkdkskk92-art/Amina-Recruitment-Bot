# Амина — Telegram Recruitment Bot

Telegram-бот для учёта анкет, собеседований, испытательного срока, голосований и репутации (REP). Бот хранит записи и напоминает о событиях; решения принимают люди.

## Стек
- Python 3.11
- aiogram 3
- SQLite через aiosqlite

## Запуск локально
1. Установите Python 3.11.
2. Создайте окружение: `python -m venv .venv`
3. Активируйте окружение и установите зависимости: `pip install -r requirements.txt`
4. Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN` и свой Telegram ID в `OWNER_ID`.
5. Запустите `python bot.py`.

## Голосования (первый реализованный модуль)
1. Откройте бота и нажмите **🗳 Голосования** (доступно владельцу, указанному в `OWNER_ID`).
2. Нажмите **Создать голосование**, введите вопрос, варианты (каждый с новой строки) и ID целевого чата/группы.
3. Бот публикует обычный неанонимный Telegram-опрос с одним выбором и возможностью изменить голос.
4. Telegram закрывает опрос через 24 часа; фоновая задача бота закрывает/проверяет опрос и отправляет итоги в чат.
5. **📚 История** показывает последние голосования и сохранённые подсчёты.

Бот должен быть участником целевой группы и иметь право отправлять сообщения/опросы. Для надёжного учёта голосов используются неанонимные опросы. Активные опросы и голоса хранятся в SQLite; незавершённый черновик создания опроса хранится только в памяти.

**Не добавляйте `.env`, токены или другие секреты в Git.**

## Разделы меню
- Анкеты
- Собеседования
- Испытательный срок (14 дней)
- Голосования (24 часа)
- Репутация
- Настройки

Начинаем с минимального запуска `/start`; функциональность разделов добавляется постепенно.
