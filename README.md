# Telegram-бот модерации

Проект заменён на бота модерации Telegram-групп. Используются Python, aiogram 3 и PostgreSQL (Bothost).

## Переменные окружения Bothost
- `BOT_TOKEN` — токен BotFather.
- `DATABASE_URL` — PostgreSQL URL из панели Bothost.
- `OWNER_TELEGRAM_ID` — Telegram ID владельца для автоматического назначения 5 ранга при первом входе.
- `LOG_LEVEL` — например `INFO`.

Не размещайте токен и пароль базы в GitHub. Пароль PostgreSQL, который ранее отправлялся в переписке, следует сменить и указать новый только в переменных окружения Bothost.

## Запуск
Команда запуска: `python main.py`. При старте таблицы создаются автоматически.

## Команды (без /)
- `профиль` или `профиль 104`
- Если у пользователя нет доступной фотографии Telegram, бот использует локальную заглушку `avatar.jpg` рядом с `main.py`.
- Отправить фото или видео с подписью `аватар` — установить аватар профиля.
- `+заметка Название` и текст со следующей строки — сохранить заметку (название до 20 символов).
- `заметка 12` — показать заметку №12.
- `-заметка 12` — удалить заметку №12.
- `-смс` — ответом на сообщение
- `варн 1 день 104`
- `молчи 10 минут 104`
- `бан 2 часа 104` или `бан навсегда 104`
- `снять варн 104`
- `говори 104`
- `разбан 104`
- `повысить 104` / `понизить 104`

Цель можно указать кастомным ID, @username или ответом на сообщение. Сроки: секунды, минуты, часы, дни, навсегда.

## Ранги
1 — удаление сообщений и варны.
2 — всё выше + мут.
3 — всё выше + бан.
4 — всё выше + изменение рангов 0–3; нельзя назначить свой ранг или выше.
5 — владелец; может назначать ранги 0–4, но не 5.

Создание, просмотр и удаление заметок доступны рангам 4–5. Форматирование Telegram-сообщения в заметке сохраняется.

Ранги общие во всех подключённых чатах. Наказания применяются только в текущем чате. Автобан ссылок также локальный для чата.

## Автоматика
- Варны истекают по заданному сроку.
- При третьем активном варне автоматически выдаётся мут на 1 час.
- Временные муты и баны снимаются фоновым заданием.
- Автобан срабатывает на ссылки-приглашения Telegram и WhatsApp.

## Важная настройка Telegram
Добавьте бота администратором в группы и выдайте права на удаление сообщений, блокировку и ограничение участников. Чтобы бот видел обычные сообщения и ссылки, отключите Privacy Mode у BotFather (`/setprivacy` → Disable).

Telegram ID используется только внутри API для выполнения действий. В пользовательских командах и профилях показывается кастомный ID.


## Репорты

- В исходной группе команда `ид чата` показывает её Telegram ID в формате `-100...`.
- В чате администрации выполните `+репорты из чата -100...` (команду может настроить пользователь с рангом 4–5). Один чат-приёмник может получать репорты из нескольких групп.
- Любой участник исходной группы может отправить жалобу сообщением:
  `репорт` и текст со следующей строки. Чтобы модераторы могли применить наказание, отправляйте репорт ответом на сообщение нарушителя.
- В карточке репорта показываются имя и кастомный ID автора, а также имя и кастомный ID пользователя, на которого пожаловались. Telegram ID остаются внутренними.
- Один активный репорт от пользователя в каждом исходном чате до рассмотрения предыдущего.
- Модераторы рассматривают жалобы кнопками: мут, бан, варн на 7 дней или отклонение. Мут и бан применяются в исходной группе; доступные действия зависят от ранга и иерархии.


## Доступ команд (ДК)

- `дк` — показать постоянные номера команд и текущие настройки; доступно только владельцу (ранг 5).
- `дк 3` — посмотреть настройку команды №3.
- `дк 3 4` — установить для команды №3 доступ с 4 ранга.
- `мдк` — показать только команды, доступные вызывающему пользователю.

Шкала: 0 — всем; 1–5 — с указанного ранга и выше; 6 — запрещено всем. Номера команд фиксированы. Саму систему ДК изменить нельзя.

## RP-команды

- `покормить @username` или команда ответом на сообщение — игровое действие.
- Вместо username можно указать внутренний ID профиля или Telegram ID.
- Следующая строка необязательна, максимум 20 символов; поддерживаются Telegram Premium Emoji.
- Второй бот `Aizen-RP-Bots` использует ту же PostgreSQL-базу и содержит только игровые команды.
