# Telegram-бот модерации

Проект заменён на бота модерации Telegram-групп. Используются Python, aiogram 3 и PostgreSQL (Bothost).

## Переменные окружения Bothost
- `BOT_TOKEN` — токен BotFather.
- `DATABASE_URL` — PostgreSQL URL из панели Bothost.
- `OWNER_TELEGRAM_ID` — Telegram ID владельца для автоматического назначения 5 ранга при первом входе.
- `LOG_LEVEL` — например `INFO`.

Не размещайте токен и пароль базы в GitHub. Пароль PostgreSQL, который ранее отправлялся в переписке, следует сменить и указать новый только в переменных окружения Bothost.

## Запуск
Команда запуска: `python main.py`. При старте таблицы создаются автоматически.

## Команды (без /)
- `профиль` или `профиль 104`
- `-смс` — ответом на сообщение
- `варн 1 день 104`
- `молчи 10 минут 104`
- `бан 2 часа 104` или `бан навсегда 104`
- `снять варн 104`
- `говори 104`
- `разбан 104`
- `повысить 104` / `понизить 104`

Цель можно указать кастомным ID, @username или ответом на сообщение. Сроки: секунды, минуты, часы, дни, навсегда.

## Ранги
1 — удаление сообщений и варны.
2 — всё выше + мут.
3 — всё выше + бан.
4 — всё выше + изменение рангов 0–3; нельзя назначить свой ранг или выше.
5 — владелец; может назначать ранги 0–4, но не 5.

Ранги общие во всех подключённых чатах. Наказания применяются только в текущем чате. Автобан ссылок также локальный для чата.

## Автоматика
- Варны истекают по заданному сроку.
- При третьем активном варне автоматически выдаётся мут на 1 час.
- Временные муты и баны снимаются фоновым заданием.
- Автобан срабатывает на ссылки-приглашения Telegram и WhatsApp.

## Важная настройка Telegram
Добавьте бота администратором в группы и выдайте права на удаление сообщений, блокировку и ограничение участников. Чтобы бот видел обычные сообщения и ссылки, отключите Privacy Mode у BotFather (`/setprivacy` → Disable).

Telegram ID используется только внутри API для выполнения действий. В пользовательских командах и профилях показывается кастомный ID.
